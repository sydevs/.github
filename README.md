# sydevs/.github

Organisation-wide defaults for the [sydevs](https://github.com/sydevs) repositories: the issue
forms anyone sees when they open an issue. Blank issues are off, so every issue arrives as a
roadmap suggestion (type `Roadmap`) or a bug report (type `Bug`).

How suggestions become work is described in
[claude-workflow](https://github.com/sydevs/claude-workflow#the-loop).
